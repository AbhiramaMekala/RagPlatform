      Pipeline trace

      Every step of the request, timed.

      1. Input check: blocks prompt injection and hides personal data.
      2. Search by meaning and search by exact words run side by side.
      3. The two result lists are merged, then a reranking model keeps the best four.
      4. Relevance check: if nothing relevant was found, it declines instead of guessing.
      5. The answer is written from those passages, then every sentence is fact-checked.
